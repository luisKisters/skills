# Stop Yapping

This skill stops agent rambling while keeping every response short, clear, self-contained, and complete. It triggers when a user says the agent is yapping, rambling, too verbose, or unclear, or asks for shorter, direct, ADHD-friendly communication.

## Install

```sh
npx skills add github.com/luisKisters/skills --skill stop-yapping
```

If the CLI is unavailable, clone or download the repository and copy the skill directory into the agent's skills directory, for example `cp -R stop-yapping ~/.codex/skills/stop-yapping`.
