# cla-coa

Installs the portable `cla` and `coa` launchers on macOS or Linux. Trigger this skill when someone asks for Claude Auto, Codex Auto, automatic approvals, or the short `cla` and `coa` commands.

Install the skill with `npx skills add github.com/luisKisters/skills --skill cla-coa`, then ask your agent to use `$cla-coa`.
