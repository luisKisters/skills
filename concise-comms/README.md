# Concise Comms

This skill makes agent responses concise, ADHD-friendly, and easy to scan in Simplified Technical English or controlled German. An agent triggers it when a user requests shorter or clearer replies, mentions ADHD or voice dictation, requests Simplified Technical English, or starts a session with this user.

## Install

```sh
npx skills add github.com/luisKisters/skills --skill concise-comms
```

If the CLI is unavailable, clone or download the repository and copy the skill directory into the agent's skills directory, for example `cp -R concise-comms ~/.codex/skills/concise-comms`.
